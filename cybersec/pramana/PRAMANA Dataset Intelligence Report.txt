PRAMANA Dataset Intelligence Report
1. Executive Summary
This report provides a verifiable reconnaissance of the provided public datasets to support the PRAMANA MVP for "Dark Web Threat Actor De-Anonymization." It maps documented dataset fields to the PRAMANA ontology, identifies false-attribution risks, prioritizes modules for MVP development, and outlines exact data transformations from raw records to derived evidence candidates.
Crucially, PRAMANA's architecture outputs assessments built from evidence, counter-evidence, independence grouping, and fusion. Public datasets are strictly isolated as extraction and training sources; they are never treated as direct attribution ground truth. RANGE-SIM is the primary hidden-ground-truth evaluation environment; RANGE-TOR is the controlled testbed for infrastructure-fingerprinting validation.

4. False-Correlation & False-Attribution Analysis
Explicit failure modes that must be handled by PRAMANA's conflict-resolution logic.
* Copied Artifacts & Mirrors (Gwern, CrimeBB): Scammers frequently copy legitimate vendor descriptions, images, and occasionally PGP keys. For example, 23 identical observations may represent 1 original artifact + 22 copies.
   * Must Not Infer: Text or image matches across markets inherently prove same-actor identity.
   * May Safely Infer: Canonicalization and clone relationships exist. PRAMANA must use hashing (SHA-256, SimHash) and shingle containment to anchor independence.
* Dataset Bias & Temporal Ambiguity (Gwern): HTML scrape_timestamp represents when the collector observed the evidence, not the user's action time.
   * Must Not Infer: The actor was actively online at scrape_timestamp.
   * May Safely Infer: The listing or key existed by that time.
* Shared Financial Infrastructure (BitcoinHeist, SNAP): Multiple distinct actors utilizing the same tumbling services, mixers, or exchange wallets.
   * Must Not Infer: Two actors sending funds to the same address are the same physical person.
   * May Safely Infer: The actors operated in the same financial ecosystem at similar times (useful for candidate pools, not specific attribution).
* Template Fingerprinting vs. Stylometry: Darknet listings use rigid templates that mask organic author syntax. Standard stylometry (F6) is for unstructured text; rigid templates belong strictly to F5 (Content Artefacts).

	6. MVP Priority Ranking
Evaluated on implementation difficulty, accessibility, data quality, evidentiary value, and integration effort.
1. BUILD NOW: Darknet Market Archives (Gwern)
   * Justification: Provides multiple cyber modalities from one corpus (PGP metadata, content artifacts, template fingerprints, clone detection, NER, and entity-resolution examples).
2. BUILD NOW: Cambridge Cybercrime Centre (CrimeBB)
   * Justification: High value for timestamps, account/post relationships, behavioral/temporal intelligence, and linguistic context.
3. BUILD NOW: RANGE-SIM & RANGE-TOR Integration
   * Justification: Crucial immediate priority. This is the only controlled evaluation environment where the system proves it does not produce ridiculous false merges.
4. BUILD LATER: Extended Brennan-Greenstein / PAN
   * Justification: Essential baseline for the ML stylometry module (F6), but secondary to extracting core modalities from Gwern and CrimeBB.
5. REFERENCE ONLY: Stanford SNAP & BitcoinHeist
   * Justification: SNAP acts as a reference topology source for hub/independence analysis. BitcoinHeist is used for wallet/transaction feature research and financial methodology, not direct attribution ground truth.

	8. Cross-Dataset Dependency & Ground Truth Isolation
* Dependency Warning: PRAMANA prevents automatic identity merging. If a Gwern vendor listing and a CrimeBB post reference the identical PGP key, this generates evidence supporting digital-identity continuity as a candidate hypothesis, which is passed to later resolution/fusion logic. It does not dictate a final attribution verdict.
* Ground Truth Isolation: Public datasets (Gwern, CrimeBB, SNAP, PAN, etc.) are strictly Training / Extraction / Corroborating Data. They contain inherent noise, copies, and attacker manipulation. RANGE-SIM is the primary hidden-ground-truth evaluation environment; RANGE-TOR is the controlled testbed for infrastructure-fingerprinting validation.
9. Major Conclusion Audit
* VERIFIED FACT: Gwern contains raw PGP text blocks, not pre-computed fingerprints. Fields listed must be treated as candidates pending verification against the archive.
* VERIFIED FACT: Scrape timestamp confirms when evidence was observed by the collector, not the exact moment of actor activity.
* SOURCE-SUPPORTED INFERENCE: Darknet listing templates artificially skew stylometry metrics, necessitating a strict separation between F5 (Content Artefacts) and F6 (Stylometry).
* DESIGN IMPLICATION: PRAMANA uses extracted data to form candidate hypotheses (e.g., "candidate same-operator") rather than absolute proof. Final system accuracy is exclusively scored against the hidden state matrices in RANGE-SIM.
